# 훈장: 사이트 공통 디자인 전환

훈장 관리자 미리보기는 Z.O.O.T. 공통 CSS와 스크립트를 사용한다. 인게임 프리팹의 절대 좌표·애니메이션·블러 렌더러를 초기화하지 않는다. 기존 추출 자료는 참고 및 회귀 검증용으로 보존한다.

- 나의 기록: 획득/가공/수집 중인 세트 수, 획득한 훈장 전시, 최근 획득 기록.
- 훈장 도감: 분류, 획득 상태, 검색, 인게임/최근 획득/이름 정렬, 목록/아이콘 보기.
- 세트 컬렉션: 수집 진행도와 훈장 미리보기. 클릭하면 세트 전체 훈장 페이지로 이동한다. 원본 컬렉션 배경은 사용하지 않는다.
- 상세창: 이미지, 상태, 설명, 획득 방법, 진행도, 가공 조건, 획득일을 문서 흐름으로 배치한다. 긴 글은 줄바꿈하고 창 높이를 넘으면 스크롤한다.
- 계정 JSON과 부모 관리자 화면의 계정 연동, 브라우저별 전시 설정은 유지한다.
- 이미지 지연 로딩과 content-visibility로 렌더링 비용을 줄인다. 목록의 모든 항목과 페이지 구조는 유지한다.
- 390px 화면에서 본문 가로 넘침이 없으며 분류 메뉴만 가로로 이동한다.

검증: 관리자 테스트 95개, Wrangler dry run. 실제 브라우저에서 계정 미연동/샘플 계정 적용, 검색, 목록/아이콘 전환, 획득한 훈장 상세, 세트 이동, 라이트/다크 테마, 390px 상세창을 확인했다. 샘플 계정 데이터와 QA 화면은 배포하지 않는다.
