사용자가 Illustrator에서 제작해 제공한 정예화·잠재·마스터리 SVG 아이콘입니다.

정예화 E1/E2는 도형의 겹치는 부분에만 그림자를 적용했습니다. 마스터리 M0–M3와 잠재 P1–P5는 제공한 형태를 유지합니다. 잠재 P6는 파란색 도형을 기준으로 흰색 발광을 적용하며, Gaussian blur 범위는 24/9 SVG 단위입니다. 발광이 잘리지 않도록 투명 여백을 포함하고 페이지에서는 아이콘 본체 크기를 보정합니다.

operators.html은 SVG를 직접 표시하며 색상 반전 필터를 사용하지 않습니다. 기존 PNG는 과거 버전 호환용으로 남겨둡니다.

E0와 P1에 포함된 검은 배경 참고용 PNG 레이어는 제거하고 벡터 도형만 사용합니다.
