# Profession and branch icons

Game artwork: Hypergryph / Yostar. Distributed assets sourced from https://github.com/PuppiizSunniiz/Arknight-Images at commit `b091aaf9b10d9fd2d181d502e3abd2e963d6618f`.

`sprite.png` packs the 8 professions and 71 branches currently present in `data/operators.json` into 64px transparent tiles, with 8 columns and 10 rows. `source.json` records upstream filenames and tile positions. Icons are served from this repository. Display at 40px and 20px; the 40%-opaque black backplates are CSS, not baked into the images.
