# Original wardrobe fonts

- `NotoSansHans-Medium` (PostScript name verified with fontTools):
  https://github.com/frappe/fonts/blob/master/usr_share_fonts/noto/NotoSansHans-Medium.otf
  Version: 2014 Adobe build; embedded license: Apache License 2.0.
  Loaded by the wardrobe stylesheet. This Simplified Chinese subset lacks Hangul;
  Noto Sans KR Medium from Google Fonts supplies Korean glyphs.
- `Novecentowide-Normal` (PostScript name verified with fontTools):
  https://github.com/darsain/sly/blob/gh-pages/font/novecentowide-normal-webfont.woff
  Version: 2.001, Jan Tonellato, 2011. Exact internal name matches the supplied prefab.
  The file's license record refers to its accompanying EULA, which this mirror does
  not contain. It is identified here but not embedded or redistributed by this app.
  Official current family / free styles / webfont distribution:
  https://typography.synthview.com/novecento-sans-font-family.php
  https://typography.synthview.com/free-quality-fonts.php
  Current free family version 3.001 must not be described as the game's verified 2.001 binary.

The first two default Ling illustrations still use screenshot calibration because
this supplied Ling bundle includes purchased illustrations only. Purchased
illustrations use the native `_skinOffset` and sprite trimming metadata.
