현재 한국 서버 개방 기간을 기준으로 계산하며 1분마다 다시 판정합니다. 복각 예정은 실제 전투 기간이 확인되어 열리기 전까지 제외합니다. 현재 상시 개방 경로가 있으면 과거 이벤트 종료 여부와 관계없이 포함합니다. 동일 스테이지 ID는 한 번만 셉니다. 개별 기록이 없으면 미완료로 간주합니다. 전체 목록의 3성/강습 완료를 증명하는 훈장이 있으면 완료 판정을 우선합니다. 직접 확인한 값은 이 화면의 메모리에만 유지됩니다.
