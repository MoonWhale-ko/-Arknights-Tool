## 구현 우선순위

1. **좌표·계층·뼈 연결**: 카메라, 부모 변환, 렌더 순서, BoneFollower를 공통 데이터로 내보낸다.
2. **기본 재질과 UV**: 가산·투명·디졸브 합성과 UV 이동·회전을 공통 처리한다.
3. **입자 기본 엔진**: 원본 곡선, 생성·수명·형상·크기·색상, 속도·노이즈를 구현한다. 효과가 없는 장식으로 대체하지 않는다.
4. **고급 공통 효과**: 왜곡/커스텀 데이터, 궤적, 하위 입자를 추가한다. Canvas 계산만으로 전부 처리하려 하지 말고 GPU 성능 검증을 별도로 진행한다.
5. **특수 구조 검토**: 스킨 메시·후처리·충돌·외부 힘이 포함된 21종을 별도 검증한다. 반드시 21종 각각의 전용 코드가 필요하다는 뜻은 아니다.

공통 고급 효과 중심인 75종과 추가 구조 검토 대상 21종으로 분류했다. **기본 합성 재질만 구현하면 75종이 곧바로 완성된다는 뜻은 아니다.**

## 해석과 한계

- 토큰을 줄이는 핵심은 캐릭터별 수작업 대신 **기능 단위 구현 + 원본 데이터 자동 내보내기 + 오류 사례만 보정**하는 것이다. 다만 최초 공통 엔진은 큰 작업이다.
- 이번 결과는 리소스 구조 분석이다. 원본 화면과의 일치, 각 효과의 활성 조건, GPU·모바일 성능은 아직 검증하지 않았다.
- 서로 다른 서버 버전을 섞어 확보했으므로, 배포용 데이터는 해당 서버·버전과 다시 맞춰야 한다.
- 현재 사이트의 보카디 고정 배경 메시 3개 지원을 전체 효과 복원 완료로 보아서는 안 된다.
- 추가 사용자 파일은 현재 필요 없다.
